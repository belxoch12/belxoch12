## 👩‍💻 Sobre mí

Construyo sistemas que resuelven necesidades reales de negocio, **desde la base de datos hasta la interfaz**: APIs REST en .NET y Node.js, aplicaciones web en React y apps móviles en Flutter y Android.

- 🏗️ Diseño backends con **arquitectura por capas**, autenticación **JWT** y permisos por rol.

- 📱 Creo apps móviles multiplataforma con **Flutter** y nativas con **Java/Kotlin**.
- 📡 Integro plataformas externas (APIs de monitoreo, servicios de Windows, bases de datos de terceros).
